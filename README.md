# SJobParser

<a id='readme-top'></a>

Desktop-приложение для парсинга вакансий с сайта SuperJob.ru. Предназначено для сбора информации о вакансиях и контактах работодателей.

## Безопасность и соблюдение правил

#### **Данный инструмент предназначен для сбора открытой информации в образовательных и исследовательских целях.**

### Рекомендуется:
- Ознакомиться с условиями использования
- Соблюдать правила сайта и robots.txt
- Не использовать для спама или нарушения правил

---

## Возможности

**Три режима работы:**

1. **Поиск объявлений по ключевому слову и городу** — автоматический поиск вакансий по заданным параметрам
2. **Поиск объявлений по URL** — парсинг вакансий по прямой ссылке
3. **Поиск телефонов** — извлечение контактных данных (имя, телефон) из вакансий

---

## Требования

- **Python**: версия 3.11 или выше
- **Google Chrome**: браузер для автоматизации (используется Playwright)
- **Подключение к интернету**

## Установка

### 1. Установите Python

- Запустите `python_installer_1.bat` или скачайте Python с [официального сайта](https://www.python.org/)
- При установке отметьте:
  - **Use admin privileges when installing py.exe**
  - 7**Add python.exe to PATH**
- Нажмите **Install Now**
- После установки появится сообщение **Setup was successful**, нажмите **Close**

### 2. Установите зависимости

Запустите в терминале:

```bash
pip install sv-ttk playwright openpyxl pandas
playwright install chromium
```

Или используйте готовый скрипт:

```bash
pip install sv-ttk pyinstaller playwright openpyxl pandas pillow asyncio
```

### 3. Запуск приложения

#### Способ 1: Через GUI (рекомендуется)

```bash
python gui.py
```

#### Способ 2: Создание EXE-файла

- Запустите `sjob_installer_2.bat`
- Дождитесь установки зависимостей и сборки EXE-файла
- На рабочем столе появится ярлык **SJobParser**

#### Способ 3: Запуск отдельных скриптов

**Поиск вакансий:**

```bash
python search_ads_sjob.py
```

В функции `main()` укажите параметры:
- `url` — URL поиска на SuperJob
- `max_vacancies` — количество вакансий

**Поиск телефонов:**

```bash
python search_phone_sjob.py
```

В функции `main()` измените `input_file` на путь к вашему Excel-файлу с ссылками на вакансии.

## Как использовать

### Режим 1: Поиск объявлений по ключевому слову

1. Выберите режим **"Поиск объявлений"**
2. Введите:
   - **Ключевое слово** (например, "Строитель")
   - **Город** (например, "Челябинск")
   - **Количество фирм** (макс. 10000)
3. Нажмите **"Начать парсинг"**
4. Результат сохранится в `superjob_parse_results/superjob_vacancies.xlsx`

### Режим 2: Поиск объявлений по URL

1. Выберите режим **"Поиск объявлений по URL"**
2. Вставьте URL страницы поиска SuperJob
3. Укажите **количество фирм**
4. Нажмите **"Начать парсинг"**

> **Совет:** Используйте кнопку **"Сгенерировать URL"** (Ctrl+G) для автоматического создания URL по ключевому слову и городу.

### Режим 3: Поиск телефонов

1. Выберите режим **"Поиск телефонов"**
2. Нажмите **"Excel файл после поиска объявлений"** и выберите файл `superjob_vacancies.xlsx`
3. Нажмите **"Вход выполнен"** (требуется авторизация в SuperJob для просмотра контактов)
4. Укажите **количество фирм**
5. Нажмите **"Начать парсинг"**
6. Результат сохранится в `superjob_vacancies_output.xlsx`

## Устранение неполадок

### Если парсер не запускается:

**Проверьте установку Python:**
```bash
python --version
```
Должна отобразиться версия 3.11 или выше.

**Проверьте установку Playwright:**
```bash
playwright install chromium
```

### Если парсинг не работает:

- ✅ Проверьте подключение к интернету
- ✅ Проверьте параметры поиска:
  - Для режима по ключу: город должен быть на русском языке
  - Для режима по URL: URL должен быть в формате `https://www.superjob.ru/vacancy/search/...`
- ✅ Проверьте авторизацию в SuperJob:
  - При сборе телефонов требуется вход в аккаунт
  - Нажмите **"Вход выполнен"** только после успешного входа
- ✅ Очистите кэш браузера:
  - Закройте все окна Chrome
  - Запустите парсинг заново

### Для обхода ограничений:

- Используйте авторизованный аккаунт — у него больше лимитов
- Чередуйте режимы работы: поиск объявлений → сбор телефонов → перерыв
- Используйте разные города — если один город вызывает проблемы
